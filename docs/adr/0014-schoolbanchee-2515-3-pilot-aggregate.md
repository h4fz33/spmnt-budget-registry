# SchoolBanchee 2515-3 Is A 17-School Pilot Aggregate

**Status:** accepted
**Date:** 2026-08-14

For the bootstrap initial pilot, SchoolBanchee uses `SB-2515-3-17-SCHOOL-AGGREGATE` as an automatically populated cross-school report derived from the submitted 2515-2 results of all 17 Schools, with columns aligned to the supplied `แบบ สพท. 2515` synthesis. This is an explicit Product Owner-approved application exception and not the original OBEC meaning of Form 2515-3; it creates no ranking, approval, return, mutation, or score-override authority, and only the narrow `AUTH-24` submitted-SAR read/aggregate boundary may expose it.
