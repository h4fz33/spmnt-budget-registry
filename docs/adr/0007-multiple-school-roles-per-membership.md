# Multiple School Roles Per Approved Membership

**Status:** accepted

An Approved Membership may hold multiple additive School Role Assignments for the same School. Public registration may request only Finance Officer; an authenticated ESAO Admin may add or remove School Admin at approval or later without replacing Finance Officer, using fresh re-authentication, a structured reason, authorization-version invalidation, and Audit Log evidence. This avoids a combined role while preserving person-level segregation of duties: School Admin does not imply Daily Balance Verifier, and this path cannot grant School Director or any ESAO/platform privilege.
