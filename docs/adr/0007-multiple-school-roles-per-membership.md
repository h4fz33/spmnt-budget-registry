# Multiple School Roles Per Approved Membership

**Status:** accepted; public-registration wording superseded for the synthetic private pilot by ADR-0017 on 2026-08-17

An Approved Membership may hold multiple additive School Role Assignments for the same School. For the synthetic private pilot, an active same-School School Admin may submit only a Finance Officer account request; an authenticated ESAO Admin alone approves it and may add or remove School Admin later without replacing Finance Officer, using fresh re-authentication, a structured reason, authorization-version invalidation, and Audit Log evidence. This avoids a combined role while preserving person-level segregation of duties: School Admin does not imply Daily Balance Verifier, and neither path can grant School Director or any ESAO/platform privilege.
