# Control Registry Is Canonical

**Status:** accepted

SchoolBanchee uses the Control Registry as the authoritative financial record and treats the Cashbook as a deliberate secondary cross-check only for Fund Flows whose effective policy requires it. This matches the subsidiary-school procedure: budget claims can be paid directly by the paying authority and Internal Money-Position Transfers are internal position changes, so creating universal cashbook or double-entry rows would invent movements and make audit totals misleading. All linked records share a Financial Event Reference, while reconciliation differences remain explicit and actionable.
