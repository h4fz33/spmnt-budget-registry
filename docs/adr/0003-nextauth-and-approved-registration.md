# NextAuth and Approved Registration

**Status:** accepted

SchoolBanchee uses NextAuth for credential authentication and route middleware, while server-side authorization remains authoritative for every command and data query. A public registration creates a Registration Application only: it grants no membership, role, or financial access until an authorized ESAO Admin approves an organization-scoped role within the permitted boundary. System Admin owns platform account/registration lifecycle, diagnostics, support, and the sealed allowlisted Initial Authorization Bootstrap, but cannot use ordinary platform authority to decide, originate, approve, reject, suspend, remove, assign, or change an organization membership, School assignment, or School-level role. Initial bootstrap configures named authenticated identities, roles, and fixed scopes without external appointment evidence; ADR-0008 and ADR-0010 govern exact post-bootstrap ESAO Admin and SESAO Auditor appointment changes. ADR-0011 permits only the technical application of the approved Policy Publisher designation and authoritative Internal Audit eligibility evidence. These privileges cannot be requested publicly; inactive membership is checked on protected server access; and the first System Admin is provisioned through a separate one-time operational bootstrap rather than public registration.
