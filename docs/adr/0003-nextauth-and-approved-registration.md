# NextAuth and Approved Registration

**Status:** accepted

SchoolBanchee uses NextAuth for credential authentication and route middleware, while server-side authorization remains authoritative for every command and data query. A public registration creates a Registration Application only: it grants no membership, role, or financial access until an authorized ESAO Admin approves an organization-scoped role within the permitted boundary. System Admin owns platform account/registration lifecycle, diagnostics, and support, but cannot decide, originate, approve, reject, suspend, remove, assign, or change an ordinary organization membership, School assignment, or School-level role. ADR-0008, ADR-0010, and ADR-0011 permit only the technical application of exact external Product Owner/accountable-reviewer appointment evidence for ESAO Admin, SESAO Auditor, and Policy Publisher primary/alternate; they grant System Admin no person or scope discretion. These privileges cannot be requested publicly; ESAO Admin membership decisions and later suspension/role changes are audited; inactive membership is checked on protected server access; and the first System Admin is provisioned through a one-time operational bootstrap rather than public registration.
