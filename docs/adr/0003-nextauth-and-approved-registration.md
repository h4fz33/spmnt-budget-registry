# NextAuth and Approved Registration

**Status:** accepted; public-registration actor semantics superseded for the synthetic private pilot by ADR-0017 on 2026-08-17

SchoolBanchee uses NextAuth for credential authentication and route middleware, while server-side authorization remains authoritative for every command and data query. The earlier public Registration Application design is historical for the current synthetic private pilot: ADR-0017 replaces it with an active School Admin-submitted, ESAO Admin-approved Finance Officer account request. It grants no membership, role, or financial access until the ESAO Admin decision within the permitted boundary. System Admin owns technical platform account/credential lifecycle, diagnostics, support, and sealed allowlisted bootstrap execution, but cannot use ordinary platform authority to decide, originate, approve, reject, suspend, remove, assign, or change an organization membership, School assignment, or School-level role. Initial bootstrap configures named authenticated identities, roles, and fixed scopes without external appointment evidence; ADR-0008 and ADR-0010 govern exact post-bootstrap ESAO Admin and SESAO Auditor appointment changes. ADR-0011 permits only the technical application of the approved Policy Publisher designation and authoritative Internal Audit eligibility evidence. Inactive membership is checked on protected server access; and the first System Admin is provisioned through a separate one-time operational bootstrap.
