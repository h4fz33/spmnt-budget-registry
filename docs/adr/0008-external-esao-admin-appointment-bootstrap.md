# External ESAO Admin Appointment Bootstrap

**Status:** accepted

SESAO Narathiwat Product Owner/accountable reviewer is the external authority that appoints or revokes an ESAO Admin. System Admin may technically apply only the exact evidence-backed appointment with fresh re-authentication and complete audit attribution, but cannot select the person, alter the fixed 17-School scope, appoint themselves, or originate organization authority. This narrowly amends ADR-0003's technical boundary without giving System Admin ordinary membership approval or School-role administration.
