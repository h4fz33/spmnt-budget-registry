# External SESAO Auditor Appointment

**Status:** accepted

During the sealed Initial Authorization Bootstrap, System Admin may configure any number of named SESAO Auditor accounts from authenticated application identity, person name, role, and SESAO Narathiwat organizational scope without appointment-document upload, evidence hash, external verification, or second-person in-application approval. Bootstrap is application configuration, not an external governmental appointment, and configuration alone grants no School or Audit Assessment access. After bootstrap, SESAO Narathiwat Product Owner/accountable reviewer originates Auditor appointment or revocation changes and System Admin may technically apply only the exact record with fresh re-authentication and full audit attribution. Assessment access begins only when creation atomically assigns the creator or ESAO Admin assigns/reassigns the Auditor under ADR-0012.
