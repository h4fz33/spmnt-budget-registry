# External SESAO Auditor Appointment

**Status:** accepted

SESAO Narathiwat Product Owner/accountable reviewer externally appoints or revokes SESAO Auditors. System Admin may technically apply only the exact evidence-backed record with fresh re-authentication and full audit attribution, but cannot select the person, alter organization-wide eligibility, appoint themselves, or originate authority. Appointment permits eligibility across all 17 Schools while actual School audit-evidence access begins only through an assigned Audit Assessment Cycle.
