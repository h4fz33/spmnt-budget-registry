# P1-23 Postgres Testing Diagnosis

**Date:** 2026-08-19
**Task:** P1-23 blocker analysis
**Blocker:** BLK-015

## Issue Summary

P1-23 Cloud Run Job is failing because the Secret Manager secret does not contain a valid test database URL. The issue is **not in the code** but in the **Secret Manager configuration**.

## Root Cause

The validation in `scripts/db-runtime.mjs` (line 76-78) requires that test database operations use a database name containing "test":

```javascript
if (!runtime.databaseName.toLowerCase().includes("test")) {
  throw new Error("Test database operations require a database name containing test")
}
```

This is a **safety check** to prevent test operations from accidentally running against production databases.

| 3 | ❌ FAIL (missing "test") | ❓ Unknown | `TEST_DATABASE_NAME_INVALID` |

## Required Fix

**The Secret Manager custodian must publish a new version** that satisfies BOTH:

1. **Database name contains "test"** (case-insensitive)
   - Expected: `schoolbanchee_test` 
   - Pattern: `*test*` anywhere in the database name
   - Example valid URLs:
     - `postgresql://user:pass@host:5432/schoolbanchee_test`
     - `postgresql://user:pass@host:5432/test_db`
     - `postgresql://user:pass@host:5432/my_testing_database`

2. **Network reachable from Cloud Run**
   - The endpoint must be accessible from the Cloud Run job
   - Version 2 had the correct name but failed connectivity
   - Version 3 fixed connectivity but broke the name requirement
