This is the canonical command-level authorization matrix for P0-04. Generic role names grant no authority beyond the commands explicitly listed here. `N/A` means the control is intentionally not required. `OPEN` means the value is unsupported and the command must fail closed.

## Global Rules

- Every runtime action uses a named authenticated principal; shared accounts are prohibited.
- The initial pilot enables no delegation. Delegated variants remain denied until a later approved Matrix amendment defines grantor, recipient eligibility, capability scope, start/expiry, revocation, invalidation, evidence, and SoD.
- No generic ESAO, platform, emergency, super-admin, or override command exists.
- A Director-required command is denied without an active School Director unless a valid Temporary Director Approval exists for that exact School, exact command, subject, and effective time. The command's original SoD, evidence, and reviewer controls still apply.
- Historical authorization and audit evidence remains attributable after later revocation or replacement.
- System Admin is a technical executor only where a row explicitly says so.
